# 🎨 GDG On-Campus SKNCOE — Official Assets & CDN Repository

This repository hosts all the official public media assets (team profile photos, event flyers, sponsor logos, and workshop resources) for the **Google Developer Groups On-Campus at Smt. Kashibai Navale College of Engineering (SKNCOE)** website.

---

## 📁 Repository Structure

```text
gdg-skncoe-assets/
├── branding/
│   ├── logos/           # GDG logos & icons (PNG, SVG)
│   └── banners/         # Social media headers & club banners
├── team/
│   ├── organizers/      # Chapter Lead & Co-Lead profile photos
│   ├── leads/           # Domain Leads (Web, AI/ML, Android, Cloud, etc.)
│   ├── coleads/         # Domain Co-Leads
│   └── mentors/         # Faculty Advisors & Mentors
├── events/
│   ├── 2026/            # Event banners, posters, and flyers (e.g. Synthera)
│   └── 2025/            # Past event archives
├── sponsors/            # Sponsor & community partner logos
└── resources/
    ├── slides/          # Workshop presentation PDFs / decks
    └── kits/            # Starter kits, cheat-sheets, guides
```

---

## ⚡ How to Use with the Website Admin Portal

1. **Upload your image or document:**
   * Push via git or drag-and-drop into the proper folder on GitHub.
2. **Copy the GitHub link:**
   * Example: `https://github.com/Google-developers-Group-SKNCOE/gdg-skncoe-assets/blob/main/team/leads/AIML%20Lead.jpg`
3. **Paste directly into the GDG Admin Panel (`/admin`):**
   * The website automatically converts the link to the fast raw CDN format (`https://raw.githubusercontent.com/...`) and displays the live preview instantly!
